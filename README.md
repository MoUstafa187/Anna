# Mami, in Every Universe

A private, five chapter love story built with plain HTML, CSS, and JavaScript. The four personal photographs stay local in `src/`; the experience does not use external fonts, services, or runtime dependencies.

## Run locally

With Node.js installed, run `npm start` (or `node server.js`) and open the address shown in the terminal. The default is `http://127.0.0.1:4173`.

## Build for production

Run `npm run build` (or `node build.js`). The self-contained static website is written to `dist/`. To preview that build, run `node server.js dist`.

The four included photographs are personal. Anyone who receives a deployed copy will be able to view them; this project has not been deployed.
